# MK Universe

**YOUR DIGITAL UNIVERSE** — تطبيق واحد يجمع السينما والمجتمع والدردشة تحت هوية MK ID.

## حالة البناء الحالية
العمل يجري على فرع مستقل: `mk-universe-rebuild`، مع إبقاء فرع `main` القديم دون تغيير.

- واجهة متجاوبة بالعربية واتجاه RTL.
- تنقل بين الرئيسية وCinema وSocial وChat والملف الشخصي.
- نموذج إنشاء حساب وتسجيل دخول بالبريد وكلمة المرور عبر Supabase Auth.
- تحميل الملف الشخصي من جدول `profiles`.
- إعادة تعيين كلمة المرور عبر البريد.
- منشورات المعاينة محلية/تجريبية حالياً وليست محفوظة في قاعدة البيانات.
- Cinema وChat حالياً شاشات تأسيسية وليستا خدمتين مكتملتين.

## الأقسام المخططة
- الرئيسية: بوابة الاكتشاف والتنقل.
- MK Cinema: كتالوج أفلام ومسلسلات، بحث وتصنيفات وقوائم مشاهدة ومصادر عرض قانونية.
- MK Social: منشورات وصور وفيديوهات، إعجاب وتعليق ومتابعة وبلاغات.
- MK Chat: محادثات فردية ومجموعات ومشاركة وسائط.
- MK ID: حساب واحد لجميع أقسام المنصة.
- MK Audience: أدوات مالك المنصة فقط، مع صلاحيات خادم وMFA وسجل عمليات.

## التقنية
- Frontend: HTML/CSS/JavaScript ES Modules.
- Backend: Supabase Auth, PostgreSQL, RLS, Storage, Realtime, Edge Functions.
- جمهور عالمي، مع واجهة عربية أولاً وإضافة الإنجليزية والفرنسية لاحقاً.

## المراحل
1. واجهة MK Universe وهوية المنتج.
2. تثبيت واختبار MK ID على رابط النشر.
3. ربط المنشورات والتفاعلات ورفع الوسائط بقاعدة البيانات.
4. بناء الدردشة الفورية والمجموعات.
5. بناء مكتبة السينما بمحتوى مرخّص أو روابط رسمية فقط.
6. بناء لوحة MK Audience، اختبارات الأمان والأداء، ثم النشر.

## الأمان
- يستخدم المتصفح مفتاح Supabase Publishable فقط؛ لا تضع أبداً service_role أو Secret Key في الواجهة.
- سياسات RLS هي خط الدفاع الأساسي لحماية بيانات المستخدمين.
- صلاحيات الإدارة يجب أن تتحقق على الخادم، لا عبر إخفاء زر في الواجهة.
- المحتوى النصي يعرض عبر textContent لتقليل مخاطر XSS.
