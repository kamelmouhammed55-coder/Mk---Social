# MK Universe

**YOUR DIGITAL UNIVERSE** — تطبيق واحد يجمع السينما والمجتمع والدردشة تحت هوية MK ID.

## ما تم بناؤه على فرع إعادة البناء
- واجهة عربية RTL متجاوبة مع هوية سوداء/فحمية وأحمر وبرتقالي وذهبي.
- الرئيسية والتنقل بين Cinema وSocial وChat وMK ID.
- Supabase Auth: تسجيل ودخول بدون كلمة مرور باستخدام رمز بريد إلكتروني من 6 أرقام (OTP)، وتسجيل الخروج.
- ملفات شخصية وتعديل الاسم واسم المستخدم والنبذة وصورة الحساب.
- منشورات محفوظة في قاعدة البيانات مع رفع صور وفيديوهات، إعجابات وتعليقات وبلاغات.
- إشعارات تلقائية للإعجاب والتعليق والمتابعة والرسائل.
- محادثات خاصة ومجموعات مع بث Realtime للرسائل، وإشعارات Realtime عند تسجيل الدخول.
- مكتبة سينما تحفظ بيانات الأفلام والمسلسلات وروابط العرض الرسمية أو المرخّصة.
- رفع ملصقات وإعلانات قصيرة إلى Storage.
- لوحة MK Audience للمالك: إحصائيات، بحث الأعضاء، تعديل الملفات، حظر/رفع حظر، حذف حساب، مراجعة البلاغات، إخفاء/حذف المنشورات، حذف التعليقات، إدارة مكتبة السينما وسجل العمليات.
- Edge Function باسم `owner-user-admin` لتنفيذ حظر Auth وحذف الحسابات من الخادم.

## المالك والأمان
- تم إعداد قائمة سماح لعنوان بريد المالك في مخطط خاص بقاعدة البيانات.
- لا يتفعّل امتياز المالك إلا بعد إنشاء حساب بهذا البريد وتأكيد البريد الإلكتروني.
- لا تستخدم `user_metadata` لتحديد صلاحيات المالك؛ قرار الصلاحية يجري في قاعدة البيانات بالتحقق من البريد المؤكد وقائمة السماح.
- عمليات الحظر والحذف تمر عبر Edge Function وتستخدم مفاتيح الخادم من أسرار Supabase الافتراضية، ولا توجد مفاتيح سرية في ملفات المتصفح.
- كل RPC إداري يتحقق من `private.is_platform_owner()` قبل أي تغيير.
- RLS مفعّل على جداول التطبيق، وStorage محمي بسياسات ملكية الملفات.
- سجل الإدارة يوثق الإجراءات الأساسية.

## السينما وحقوق العرض
قاعدة البيانات تشترط HTTPS ومصدر المحتوى وأساس الحقوق: ترخيص، ملك عام موثق، أو مصدر رسمي. المنصة لا تستضيف نسخاً غير مرخصة من الأفلام؛ رابط المشاهدة يجب أن يكون مصدراً يملك حق العرض أو يصرح به.

## التقنية
- Frontend: HTML/CSS/JavaScript ES Modules.
- Backend: Supabase Auth, PostgreSQL, RLS, Storage, Realtime, Edge Functions.
- Supabase project: France region.

## التحقق والاختبارات
- `npm run check` يفحص صياغة JavaScript ويشغّل اختبارات smoke بسيطة للتحقق من عناصر HTML وتدفق OTP ونشر الوسائط.
- نجاح الاختبارات الثابتة لا يغني عن اختبارات المتصفح الفعلية وتكامل Supabase.

## ما يلزم قبل الإطلاق
1. إنشاء حساب المالك بالبريد المصرح به وتأكيده، ثم التحقق من ظهور لوحة MK Audience.
2. اختبار التسجيل والدخول والنشر والرفع والحظر والحذف والدردشة من متصفح حقيقي.
3. اختبار Edge Function مع جلسة مالك وجلسة عضو عادي للتأكد من رفض غير المالك.
4. مراجعة إعدادات البريد وRedirect URLs وخصوصية المشروع.
5. إكمال سياسة الخصوصية وشروط الاستخدام وآلية البلاغات والاستجابة لها.
6. مراجعة حدود Storage والتكلفة وخطة استضافة الفيديو قبل فتح التسجيل للجمهور.
7. بعد نجاح الاختبارات فقط، دمج الفرع إلى `main` ونشر GitHub Pages.

## الفروع والنشر

- `mk-universe-rebuild`: فرع البناء الجديد.
