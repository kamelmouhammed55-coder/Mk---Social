# MK Social

**YOUR DIGITAL UNIVERSE** — النسخة الأولية القابلة للتجربة من MK Social.

## ما يعمل في هذه النسخة
- إنشاء حساب بالبريد وكلمة المرور وتسجيل الدخول والخروج.
- إرسال رابط إعادة تعيين كلمة المرور.
- إنشاء/تحديث الملف الشخصي (اسم المستخدم والنبذة).
- نشر منشورات نصية وقراءة أحدث 30 منشوراً.
- الإعجاب وإلغاء الإعجاب.
- عرض التعليقات وإضافة تعليق.
- البحث عن الأعضاء بالـ username ومتابعتهم/إلغاء متابعتهم.

## البنية
- `index.html`: الهيكل والواجهة.
- `styles.css`: التصميم المتجاوب والألوان.
- `app.js`: منطق التطبيق واتصال Supabase.

## التقنيات
HTML/CSS/JavaScript Modules، Supabase JS v2.89.0، Supabase Auth + Postgres + RLS، وGitHub Pages.

## النشر عبر GitHub Pages
1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واضغط Save.
3. أضف رابط الموقع الناتج في Supabase: **Authentication → URL Configuration** ضمن Site URL وRedirect URLs.
4. اختبر التسجيل، تأكيد البريد، تسجيل الدخول واسترجاع كلمة المرور.

## الأمان
- التطبيق يستخدم Publishable Key فقط. لا تضع أبداً service_role أو Secret API key في ملفات الواجهة.
- سياسات RLS في قاعدة البيانات هي خط الدفاع الأساسي.
- عرض محتوى المستخدم يتم عبر `textContent` لتقليل خطر XSS.
- قبل الإطلاق العام، أضف سياسة خصوصية، شروط استخدام، آلية بلاغات/حظر وإشراف وحدوداً لمكافحة السبام.

## حدود النسخة الحالية
- لا يوجد رفع صور أو فيديو؛ لم يتم إنشاء Storage bucket بعد.
- لا توجد واجهة دردشة أو إشعارات حية في هذه النسخة.
- يلزم اختبار التسجيل وتأكيد البريد على رابط Pages بعد ضبط Redirect URLs.
