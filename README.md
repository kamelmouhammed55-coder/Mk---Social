# MK Universe

**YOUR DIGITAL UNIVERSE** — تطبيق واحد يجمع السينما والمجتمع والدردشة تحت هوية MK ID.

## حالة المشروع
هذه هي المرحلة الأولى: واجهة أولية متجاوبة (Prototype) مبنية من الصفر على فرع `mk-universe-rebuild`. البيانات المعروضة تجريبية وليست متصلة بقاعدة البيانات بعد.

## الأقسام المخططة
- الرئيسية: بوابة الاكتشاف والتنقل.
- MK Cinema: كتالوج أفلام ومسلسلات، بحث وتصنيفات وقوائم مشاهدة ومصادر عرض قانونية.
- MK Social: منشورات وصور وفيديوهات، إعجاب وتعليق ومتابعة وبلاغات.
- MK Chat: محادثات فردية ومجموعات ومشاركة وسائط.
- MK ID: حساب واحد لجميع أقسام المنصة.
- MK Audience: أدوات مالك المنصة فقط، مع صلاحيات خادم وMFA وسجل عمليات.

## التقنية المخططة
- Frontend: HTML/CSS/JavaScript في النموذج الأولي.
- Backend: Supabase Auth, PostgreSQL, RLS, Storage, Realtime, Edge Functions.
- جمهور عالمي، مع واجهة عربية أولاً وإضافة الإنجليزية والفرنسية لاحقاً.

## المراحل
1. اعتماد الواجهة وتجربة التنقل.
2. بناء MK ID والتوثيق الآمن.
3. ربط المنشورات والتفاعلات ورفع الوسائط.
4. بناء الدردشة الفورية والمجموعات.
5. بناء مكتبة السينما بمحتوى مرخّص أو روابط رسمية فقط.
6. بناء لوحة MK Audience، اختبارات الأمان والأداء، ثم النشر.

## الأمان
لا توجد مفاتيح Supabase أو أسرار في هذه النسخة. لا تضع مفتاح service_role أو Secret Key في كود المتصفح. كل صلاحية إدارية يجب أن تتحقق على الخادم، لا عبر إخفاء زر في الواجهة.
